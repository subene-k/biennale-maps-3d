# 360° photos

Put 360° photos for the map here (2:1 equirectangular JPEG, ideally 4096×2048 and under 5 MB so phones load them quickly).

Then link a photo to a place in `../pois.json` by adding a `pano` field, for example:

```json
{"id":"diwaniam","name":"Diwan-i-Aam", ..., "pano":"panos/diwan-i-aam.jpg"}
```
